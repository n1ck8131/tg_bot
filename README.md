# Birthday Party Bot

Telegram-бот для организации дня рождения с играми, конкурсами и интеграцией с Яндекс.Музыкой.

## ✨ Возможности

### 🎮 Для гостей

**В групповом чате:**
- `/start` — главное меню с inline-кнопками
- Информация о мероприятии (место проведения, выезд, вишлист)
- Геопозиция места проведения
- Отправка сообщений организатору
- Просмотр плейлиста вечеринки

**В личных сообщениях боту:**
- Участие в фото-конкурсе (просто отправь фото, если конкурс открыт)
- Добавление треков в плейлист Яндекс.Музыки (просто отправь ссылку)
- Регистрация на игру "Достать ножи" (кнопка появляется в групповом чате при открытии регистрации)

### 👨‍💼 Для организатора (админ-панель)

| Функция | Описание |
|---------|----------|
| 📸 Фото-конкурс | Запуск конкурса → Приём фото → Голосование с кнопками → Объявление победителя (макс. 22 участника) |
| 🏆 Турнир бир-понга | Турнирная система с автоматической генерацией команд и сетки плей-офф |
| 🔪 Достать ножи | Полноценная игра с регистрацией, кольцевой системой заданий и финальным отчётом |
| 📊 Опросы | Создание опросов с одним или несколькими вариантами ответа |
| 📢 Broadcast | Отправка объявлений в групповой чат |
| 📍 Геопозиция | Установка и обновление места проведения |
| 🎵 Яндекс.Музыка | Добавление треков в плейлист вечеринки |
| ✉️ Ответы на сообщения | Прямой ответ на вопросы гостей из админ-панели |

## 📸 Фото-конкурс

Интерактивный фото-конкурс с кнопочным голосованием:

### Процесс проведения

1. **Начало конкурса:** Админ запускает приём фото — анонс приходит в группу
2. **Приём фото:** Участники отправляют фото в личку боту (макс. 22 участника)
3. **Завершение приёма:** Админ останавливает приём фото
4. **Публикация:** Админ запускает голосование — все фото публикуются в группе с подписями авторов
5. **Голосование:** Бот отправляет сообщение с кнопками для голосования за каждое фото
6. **Голоса:** Участники нажимают на кнопку нужного фото (один голос на человека, за себя голосовать нельзя)
7. **Результаты:** Админ завершает голосование — бот публикует результаты с поздравлением победителя

### Особенности

- **Кнопочное голосование:** Вместо стандартных опросов Telegram — удобные inline-кнопки
- **Защита от накруток:** Один голос на человека, за своё фото голосовать нельзя
- **Всплывающие уведомления:** При голосовании показывается подтверждение "Вы проголосовали за #"
- **Автоматический подсчёт:** Результаты с медалями 🥇🥈🥉 и общим количеством голосов
- **Напоминание о формате:** Если участник отправляет фото в группу вместо личного чата — бот напоминает, куда нужно отправлять
- **До 22 участников:** Масштабируется для больших компаний
- **Тестовый режим для админа:** Организатор может отправлять неограниченное количество фото для тестирования голосования

## 🔪 Игра "Достать ножи"

Главная фишка бота — полнофункциональная игра для вечеринки:

### Как играть

1. **Регистрация:** Организатор открывает регистрацию, в группу приходит сообщение с кнопкой регистрации
2. **Настройка:** Организатор задаёт списки оружий и локаций (есть дефолтные)
3. **Старт:** Каждый игрок получает задание: цель (другой игрок), оружие и локацию
4. **Игра:** Игроки "убивают" свои цели, жертва подтверждает смерть кнопкой "Я мёртв"
5. **Цепочка:** После смерти убийца получает цель своей жертвы с новым оружием/локацией
6. **Победа:** Игра продолжается до последнего выжившего
7. **Отчёт:** В конце — полная хронология убийств с временем и путь победителя

### Особенности

- **Безопасная зона:** "курилка" — убийства там запрещены
- **Персистентность:** SQLite база, игра переживает перезапуски бота
- **Тестовый режим:** Организатор может прогнать игру с виртуальными игроками для отладки
- **Конфиденциальность:** Анонсы смертей не раскрывают убийцу
- **До 22 участников:** Масштабируется для больших компаний
- **Пошаговые инструкции:** Встроенные подсказки в тестовом режиме
- **Устрашающие сообщения:** Атмосферные тексты для погружения в игру

### Админ-функции

- **Открытие регистрации** — объявление в группу с правилами
- **Настройка оружий и локаций** — кастомные списки (ложка, вилка, носок...)
- **Запуск игры** — автоматическое распределение целей по кольцу
- **Тестовый режим** — симуляция с виртуальными игроками
- **Управление виртуальными игроками** — пошаговое управление тестовой игрой
- **Финальный отчёт** — хронология с временем + путь победителя

## 📦 Установка и запуск

```bash
git clone https://github.com/n1ck8131/tg_bot.git
cd tg_bot
```

### 2. Создание виртуального окружения

```bash
python -m venv venv

venv\Scripts\activate

source venv/bin/activate
```

```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните значения:


## 🔑 Получение токенов и ID

### BOT_TOKEN

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен

### ADMIN_ID

1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID

### GROUP_ID

1. Добавьте бота [@RawDataBot](https://t.me/RawDataBot) в группу
2. Скопируйте значение `chat.id` из ответа (отрицательное число)
3. Удалите RawDataBot из группы

### YANDEX_MUSIC_TOKEN (опционально)

1. Авторизуйтесь на [music.yandex.ru](https://music.yandex.ru)
2. Откройте DevTools (F12) → Application → Cookies
3. Скопируйте значение `Session_id`

### YANDEX_PLAYLIST_KIND

1. Откройте нужный плейлист в Яндекс.Музыке
2. Скопируйте число из URL: `music.yandex.ru/users/USERNAME/playlists/PLAYLIST_KIND`

## 🏗 Архитектура

### Модульная структура обработчиков

Бот использует систему роутеров aiogram для разделения логики:

- `admin_router` — команды администратора (личный чат)
- `assassin_router` — обработчики игры "Достать ножи"
- `tournament_router` — обработчики турнира бир-понга
- `user_router` — команды обычных пользователей (личный чат)
- `group_router` — команды группового чата

### FSM (Finite State Machine)

Для многошаговых диалогов используются состояния:

- `AskState` — отправка сообщения организатору
- `GeoState` — установка геопозиции
- `AdminBroadcastState` — отправка объявления
- `AdminPollState` — создание опроса (один или несколько ответов)
- `TournamentState` — управление турниром
- `AssassinState` — настройка и управление игрой "Достать ножи"

### Хранилища данных

#### In-memory (временное хранение)

- `polls_storage` — опросы и результаты голосований (TTL: 24 часа)
- `photo_contest_storage` — фотографии участников конкурса (макс. 22 участника)
- `forwarded_messages_storage` — связь пересланных сообщений (TTL: 1 час)
- `location_storage` — геопозиция места проведения
- `tournament_storage` — турнир бир-понга

#### SQLite (персистентное хранение)

Игра "Достать ножи" использует персистентное хранилище в SQLite (`assassin_game.db`):

- `game` — информация об играх (статус, тестовый режим, победитель)
- `player` — игроки (реальные и виртуальные)
- `contract` — активные задания (убийца → цель + оружие + локация)
- `kill_log` — история убийств с временными метками
- `weapon` — список оружий
- `location` — список локаций

**Все операции транзакционные. Данные переживают перезапуски бота.**

### Middleware и безопасность

Бот защищен от злоупотреблений:

- **Rate Limiting** — ограничение частоты запросов (10 сообщений/30 сек, 20 callback/30 сек)
- **Markdown Sanitization** — экранирование специальных символов в пользовательском вводе
- **Error Handling** — глобальный обработчик ошибок с логированием
- **Graceful Shutdown** — корректное закрытие соединений при остановке
- **Race Condition Prevention** — блокировки для критических операций
- **Database Transactions** — атомарность операций с БД

### Фильтры

Переиспользуемые фильтры для обработчиков (`app/filters.py`):

- `IsAdminPrivateFilter` — приватные сообщения от администратора
- `IsUserPrivateFilter` — приватные сообщения от обычных пользователей
- `IsGroupChatFilter` — сообщения из группового чата

## 🔧 Масштабирование

Для production-использования рекомендуется:

1. **Персистентное хранилище** — заменить in-memory хранилища на Redis (кроме игры, она уже использует SQLite)
2. **Webhook-режим** — использовать webhook вместо polling для снижения нагрузки
3. **Логирование** — настроить отправку логов в систему мониторинга (Sentry, ELK)
4. **Мониторинг** — добавить метрики (Prometheus) для отслеживания производительности
5. **Backup БД** — настроить автоматическое резервное копирование `assassin_game.db`

### Уже реализовано

- ✅ **Graceful shutdown** — корректное закрытие соединений при остановке
- ✅ **Rate limiting** — защита от спама и DoS атак
- ✅ **Global error handler** — централизованная обработка исключений
- ✅ **SQLite персистентность** — игра "Достать ножи" переживает перезапуски
- ✅ **Транзакционность** — все критические операции атомарны

## ✏️ Редактирование текстов бота

Все тексты бота вынесены в один файл для удобства редактирования.

**Файл с текстами:** `app/messages.py`

📖 **Подробная инструкция:** [`TEXTS.md`](TEXTS.md)

### Быстрый старт

1. Откройте файл `app/messages.py`
2. Найдите нужное сообщение (например, `WELCOME_USER`, `TRACK_ADDED`)
3. Измените текст
4. Сохраните и перезапустите бота

**Примеры:**
```python
# Приветствие пользователя
WELCOME_USER = "Привет! 👋\n\nЯ бот для организации вечеринки."

# Сообщение об успешном добавлении трека
TRACK_ADDED = "Трек добавлен!\n\n*{title}*\nДобавил: {user}"

# Надпись на кнопке
ButtonLabels.ADD_TRACK = "🎵 Добавить трек"
```

**Структура файла:**
- `Messages` — все сообщения бота (приветствия, ошибки, информация)
- `ButtonLabels` — надписи на кнопках
- `Emojis` — эмодзи для оформления

⚠️ **Важно:**
- НЕ удаляйте `{переменные}` в фигурных скобках
- НЕ меняйте названия констант
- Перезапускайте бота после изменений
